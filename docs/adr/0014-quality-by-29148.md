# ADR-0014: 要求品質の基準は ISO/IEC/IEEE 29148、文型は EARS を任意で

- 状態: Accepted
- 日付: 2026-11-19

## 状況

会話第 4・5 回: 29148 は「曖昧でない・一貫した・検証可能な要求」の基準であり、検証ルールの根拠にする。

## 決定

- 要求の属性は 29148 が例示する属性（識別、版、所有者、優先度、リスク、理由、難易度、種類）を中心に、検証方法・レベル・出所・状態・トレースを加える。
- 個々の要求の 9 特性（necessary, appropriate, unambiguous, complete, singular, feasible, verifiable, correct, conforming）を、機械で検査できるもの（L4 ルール）と人が判断するもの（narrative）に分ける。
- 文型は EARS のパターン名を任意で記録する。日本語の文型は「〜しなければならない／してはならない」を既定とする（プロジェクトで変更可）。
- 規格本文は同梱せず、特性名・属性名のみ参照する。

## 検討した代替案

- 独自の品質基準: 根拠が弱く、組織間で共有しにくい。
- EARS を必須にする: 日本語の要求文に機械的に当てはめにくい。

## 結果

- 曖昧語レキシコンは言語ごとに保守が必要。誤検出は FB としてコアルールに戻す。
