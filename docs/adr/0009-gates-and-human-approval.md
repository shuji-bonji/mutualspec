# ADR-0009: ゲートと人の承認: 機械条件は必要条件、G1 / G4 の人の承認は必須

- 状態: Accepted
- 日付: 2026-11-19

## 状況

会話第 5 回で「ループの終了条件（検証をすべて通過したことを人が確認するのか、自動で次に進むのか）」を決める必要があるとされた。

## 決定

- 5 つのゲート G0（範囲合意）、G1（仕様承認）、G2（ビルド）、G3（検証完了）、G4（ループ終了）。
- 機械条件は設定可能（狭める方向を推奨）。G0 / G1 / G4 は人の承認を伴い、G1 と G4 の人の承認は外せない。
- 機械条件を満たさずに通す場合は `waived` と理由を記録する。
- 内側ループ（LLM の起草 → 検証 → 修正）は自動で回すが、上限回数（既定 3）で人にエスカレーションする。

## 検討した代替案

- 全自動: 相互理解の最終責任が不在になる。
- 全手動: ループの速度が出ず、検証が形骸化する。

## 結果

- PR の必須レビュー（CODEOWNERS）で人の承認を実現する。
